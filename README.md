# <img src="https://raw.githubusercontent.com/HeddleFlow/HeddleFlow/main/.github/assets/heddleflow-mark.svg" alt="" height="32"> HeddleFlow Help

**The help for HeddleFlow's users: what HeddleFlow is, how its ideas fit together, and how to get each thing done.**

HeddleFlow works with AI agents to build a new product from an idea, or grow an existing one from a change, through to
release. The product, its releases and its issues are in [HeddleFlow/HeddleFlow](https://github.com/HeddleFlow/HeddleFlow).
This repository holds only the help, which the HeddleFlow website publishes.

> **Status: being written.** The help arrives with HeddleFlow's first public release.

## How it is organised

- **By concept, then by task.** The help explains each idea once, then shows how to use it, and closes with reference.
  It follows how a person thinks about the work, never how the code is built.
- **One folder per language**, starting with English in `en/`. Every translation keeps the same pages and the same
  paths, so a link works in every language.
- **One version per release.** When a HeddleFlow release goes public, this repository is tagged with its version, such
  as `v1.0.0`, and the website publishes the help of that tag. The help of every release stays readable, so a project
  pinned to an older release finds the help that matches it.

## Contributing

Contributions, translations among them, open later, alongside HeddleFlow's own. Until then, report a mistake in the
help through [HeddleFlow's issues](https://github.com/HeddleFlow/HeddleFlow/issues).
